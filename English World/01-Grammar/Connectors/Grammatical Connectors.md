## Formal Grammatical Connectors

| **Grammatical Connector** | **Meaning (Spanish)**              | **Example**                                                                            |
| ------------------------- | ---------------------------------- | -------------------------------------------------------------------------------------- |
| Within                    | Dentro de / en                     | The issue is within the customer portal.                                               |
| Whether                   | Si / si... o...                    | I don't know whether the fix will be ready today.                                      |
| Nevertheless              | No obstante / aun así              | The deployment was challenging; nevertheless, we completed it successfully.            |
| Otherwise                 | De lo contrario / si no            | We must validate the pipeline; otherwise, the deployment may fail.                     |
| Furthermore               | Además / asimismo                  | Furthermore, we need to review the server logs.                                        |
| Moreover                  | Además / es más                    | Moreover, the latest tests revealed another issue.                                     |
| However                   | Sin embargo                        | The service is running; however, some requests are still failing.                      |
| Therefore                 | Por lo tanto                       | The dependency failed; therefore, the batch job could not start.                       |
| Consequently              | En consecuencia                    | The database was unavailable. Consequently, the transaction failed.                    |
| Although                  | Aunque                             | Although the deployment succeeded, the application is still unstable.                  |
| Even though               | Aunque / a pesar de que            | Even though the server is healthy, the application is returning errors.                |
| Whereas                   | Mientras que / en cambio           | The primary server is available, whereas the secondary server is offline.              |
| Despite                   | A pesar de                         | Despite the delay, we completed the deployment.                                        |
| In spite of               | A pesar de                         | In spite of the network issue, the transfer completed successfully.                    |
| In addition               | Además                             | In addition, we need to verify the monitoring alerts.                                  |
| In addition to            | Además de                          | In addition to checking the logs, we reviewed the configuration.                       |
| As a result               | Como resultado                     | The file was missing. As a result, the batch process failed.                           |
| For this reason           | Por esta razón                     | The service was unavailable. For this reason, we escalated the incident.               |
| Accordingly               | En consecuencia / por consiguiente | The requirements changed; accordingly, we updated the configuration.                   |
| Thus                      | Así / por lo tanto                 | The token expired; thus, the authentication request was rejected.                      |
| Hence                     | De ahí que / por lo tanto          | The connection was refused; hence, the application could not reach the server.         |
| In contrast               | En contraste                       | In contrast, the test environment is working as expected.                              |
| On the other hand         | Por otro lado                      | The fix is straightforward. On the other hand, testing may take several hours.         |
| In particular             | En particular                      | We need to investigate the failed jobs, in particular those with missing dependencies. |
| Specifically              | Específicamente / concretamente    | Specifically, we need to check the connection timeout.                                 |
| Regarding                 | Con respecto a                     | Regarding the incident, we are still waiting for the customer's response.              |
| Concerning                | En cuanto a / con respecto a       | Concerning the deployment, all validation checks have passed.                          |
| In terms of               | En términos de / en cuanto a       | In terms of performance, the new configuration is more efficient.                      |
| In the event that         | En caso de que                     | In the event that the service fails, contact the on-call engineer.                     |
| Provided that             | Siempre que / con tal de que       | The deployment can proceed, provided that all tests pass.                              |
| Unless                    | A menos que                        | We should not restart the service unless it is necessary.                              |
| To that end               | Con ese fin / para ello            | We need to reduce processing time. To that end, we are reviewing the job dependencies. |
| In the meantime           | Mientras tanto                     | The team is investigating the issue. In the meantime, we are monitoring the service.   |
| Subsequently              | Posteriormente                     | We restarted the service and subsequently verified its status.                         |
| Prior to                  | Antes de                           | Prior to deployment, we must validate the configuration.                               |
| Following                 | Después de / tras                  | Following the restart, the service returned to normal.                                 |
| With regard to            | En relación con / respecto a       | With regard to the incident, the root cause remains unknown.                           |
| In accordance with        | De acuerdo con / conforme a        | The changes were implemented in accordance with the approved procedure.                |
| To summarize              | En resumen                         | To summarize, the issue was caused by a missing input file.                            |
| Ultimately                | En última instancia / finalmente   | Ultimately, we need to identify the root cause.                                        |


## Informal and Conversational Connectors

| **Connector / Expression** | **Meaning (Spanish)**              | **Example**                                                               |
| -------------------------- | ---------------------------------- | ------------------------------------------------------------------------- |
| By the way                 | Por cierto                         | By the way, I've finished the report.                                     |
| Anyway                     | En fin / de todos modos            | Anyway, let's get back to the incident.                                   |
| So                         | Entonces / así que                 | So, what should we check next?                                            |
| Well                       | Bueno / pues                       | Well, I think we should check the logs first.                             |
| Actually                   | En realidad / de hecho             | Actually, the service restarted automatically.                            |
| Besides                    | Además / aparte de eso             | Besides, we haven't checked the network logs yet.                         |
| Plus                       | Además / aparte                    | Plus, we need approval before making that change.                         |
| Also                       | También / además                   | Also, I noticed another failed job.                                       |
| On top of that             | Además de eso / para colmo         | The server was slow, and on top of that, the connection kept dropping.    |
| Even so                    | Aun así                            | The logs look normal. Even so, we should investigate further.             |
| Still                      | Aun así / de todas formas          | The fix is not ideal. Still, it should resolve the immediate issue.       |
| That said                  | Dicho eso / aun así                | The service is stable. That said, we should continue monitoring it.       |
| In that case               | En ese caso                        | In that case, let's escalate the incident.                                |
| If so                      | Si es así                          | If so, we can proceed with the deployment.                                |
| If not                     | Si no / de lo contrario            | Check whether the file exists. If not, contact the customer.              |
| As for                     | En cuanto a / respecto a           | As for the second issue, we're still investigating.                       |
| As far as I know           | Hasta donde sé                     | As far as I know, the deployment is scheduled for tonight.                |
| From what I can tell       | Por lo que puedo ver               | From what I can tell, the process is stuck.                               |
| It turns out               | Resulta que                        | It turns out the input file was missing.                                  |
| The thing is               | Lo que pasa es que                 | The thing is, we don't have access to that server.                        |
| I mean                     | Es decir / o sea                   | I mean, the service is up, but requests are still failing.                |
| For example                | Por ejemplo                        | For example, we can check the logs before restarting the service.         |
| Like                       | Como / por ejemplo                 | Some errors, like connection timeouts, can indicate a network issue.      |
| In other words             | En otras palabras                  | In other words, the job depends on another process finishing first.       |
| At least                   | Al menos                           | At least, we know the database is responding.                             |
| At the same time           | Al mismo tiempo / a la vez         | We need to investigate the issue while keeping the service available.     |
| For now                    | Por ahora                          | For now, let's monitor the service.                                       |
| So far                     | Hasta ahora                        | So far, we haven't found the root cause.                                  |
| Once again                 | Una vez más                        | Once again, the batch job failed at the same step.                        |
| After all                  | Después de todo / al fin y al cabo | After all, we need to verify the fix before closing the incident.         |
| Either way                 | De cualquier manera                | Either way, we need to inform the customer.                               |
| No worries                 | No te preocupes / no hay problema  | No worries, I'll take a look at it.                                       |
| Just so you know           | Para que lo sepas                  | Just so you know, the maintenance window has changed.                     |
| Just keep in mind          | Solo ten en cuenta                 | Just keep in mind that the deadline is tomorrow.                          |
| One more thing             | Una cosa más                       | One more thing: we need to update the incident ticket.                    |
| Before I forget            | Antes de que se me olvide          | Before I forget, did you check the latest alerts?                         |
| To be honest               | Para ser sincero                   | To be honest, I'm not sure what caused the failure.                       |
| Either way                 | En cualquier caso                  | Either way, we should document what we found.                             |
| Long story short           | En pocas palabras / para resumir   | Long story short, the deployment failed because of a configuration issue. |
| Anyway, back to...         | En fin, volviendo a...             | Anyway, back to the main issue: the service is still unavailable.         |
| At the end of the day      | Al final / en última instancia     | At the end of the day, our priority is to restore the service.            |
| In the first place         | Para empezar / en primer lugar     | We should have checked the dependencies in the first place.               |


#### Using them

### 1. Actually

- Actually, I was about to tell you the same thing.
    
- Actually, that's not what I meant.
    
- Actually, I think we should try something else.
    

### 2. By the way

- By the way, did you check the ticket I sent you?
    
- Oh, by the way, thanks for your help earlier.
    
- By the way, do you know when the meeting starts?
    

### 3. That said

- That said, I think we should give it another try.
    
- The fix seems to be working. That said, we should keep monitoring it.
    
- That said, I understand your point.
    

### 4. As far as I know

- As far as I know, the meeting is still scheduled for tomorrow.
    
- As far as I know, nobody has reported any issues.
    
- As far as I know, everything is working as expected.
    

### 5. From what I can tell

- From what I can tell, everything looks fine.
    
- From what I can tell, the issue is on the customer's side.
    
- From what I can tell, the process is stuck.
    

### 6. In that case

- In that case, let's wait for their response.
    
- In that case, I'll take care of it.
    
- In that case, we should probably escalate the issue.
    

### 7. So far

- So far, everything is going well.
    
- So far, we haven't found the root cause.
    
- So far, I've managed to resolve most of the issues.
    

### 8. In the meantime

- I'll check the logs. In the meantime, could you check the dashboard?
    
- In the meantime, I'll keep you updated.
    
- The team is investigating the issue. In the meantime, we're monitoring the service.
    

### 9. Otherwise

- We need to fix this now; otherwise, it could happen again.
    
- Let me know if you need anything. Otherwise, I'll get back to work.
    
- Make sure you save your changes; otherwise, you'll lose your progress.
    

### 10. As a result

- The server went down. As a result, several jobs failed.
    
- We updated the configuration, and as a result, the errors stopped.
    
- He missed the deadline and, as a result, had to reschedule the meeting.
    

### 11. Unless

- I won't make any changes unless I get approval.
    
- We won't be able to finish on time unless we resolve this issue.
    
- You won't know whether it works unless you test it.
    

### 12. That being said

- That being said, I still think it's worth trying.
    
- That being said, I understand why they made that decision.
    
- I know we're running out of time. That being said, we shouldn't rush the testing.
