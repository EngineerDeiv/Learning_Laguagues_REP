
### More used

| **Modal Verb** | **Meaning**                 | **Example**                         |
| -------------- | --------------------------- | ----------------------------------- |
| Can            | Poder, saber (habilidad)    | I can troubleshoot Linux servers.   |
| Could          | Podría, podía               | Could you check the logs?           |
| May            | Puede que, tener permiso    | May I ask a question?               |
| Might          | Podría, quizás              | The server might be down.           |
| Must           | Deber, tener que            | You must restart the service.       |
| Shall          | Deber (oferta o sugerencia) | Shall we start the meeting?         |
| Should         | Debería                     | You should check the configuration. |
| Will           | Futuro, voluntad            | I will investigate the issue.       |
| Would          | Haría, gustaría             | Would you help me with this task?   |
| Ought to       | Debería                     | You ought to update the system.     |
| Need           | Necesitar                   | You need not restart the server.    |
| Dare           | Atreverse a                 | Dare I ask what happened?           |

### More formal

| **Modal Verb** | **Meaning**                | **Example**                              |
| -------------- | -------------------------- | ---------------------------------------- |
| Have to        | Tener que                  | I have to attend the meeting.            |
| Has to         | Tiene que                  | He has to check the dashboard.           |
| Had to         | Tuvo que / tenía que       | I had to restart the service.            |
| Be able to     | Ser capaz de / poder       | I will be able to fix the issue.         |
| Be allowed to  | Tener permiso para         | We are allowed to access the server.     |
| Be supposed to | Se supone que debe         | You are supposed to monitor the process. |
| Had better     | Más vale que / sería mejor | You had better check the logs.           |
| Used to        | Solía                      | I used to work with Linux daily.         |
